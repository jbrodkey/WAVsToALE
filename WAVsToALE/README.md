# WAVsToALE

Generate ALE files from WAV metadata (BEXT, LIST-INFO, embedded XML) with optional UCS auto-categorization for fast bin prep and editorial workflows.

## Project layout

```
WAVsToALE/
├── README.md                                # Main documentation (this file)
├── wav_to_ale_with_bext_xml_v2_plusUCS-Parsing.py  # Main script (GUI/CLI)
├── build.sh                                  # PyInstaller build helper (macOS)
├── requirements.txt                          # Minimal Python deps
├── .gitignore                                # Ignore build artifacts, caches, DMG staging, etc.
│
├── data/                                      # Runtime data packaged with the app
│   └── UCS_v8.2.1_Full_List.csv               # UCS categories (preferred location)
│
├── icons/                                     # App icons and artwork
│   ├── WAVsToALE_512.png (example)
│   ├── mac/
│   └── win/
│
├── packaging/                                 # Packaging assets (kept out of the root)
│   ├── DMG_/                                  # DMG background, icns, scripts, archives
│   └── WAVsToALE.spec                         # PyInstaller spec (autogenerated/maintained)
│
├── docs/                                      # Extra guides and platform notes
│   ├── BUILD_GUIDE.md
│   ├── README_mac.txt
│   ├── README_windows.txt
│   ├── README_windows_build.txt
│   ├── WAVsToALE README.rtf                   # RTF styled version for parity
│   └── version_info.txt
│
└── archive/                                   # Legacy experiments/tests kept for reference
    └── (older prototypes, test scripts)
```

Notes:
- The script prefers `data/` for UCS CSVs and is packaged with `--add-data ...:data` so it works in dev and in frozen apps.
- `docs/` centralizes all supplemental documentation to keep the repo root clean.
- `packaging/` holds DMG assets and the spec; `build.sh` remains at root for convenience, but can be moved if you prefer.
- `archive/` is optional and can be pruned anytime; it’s not required for running or building.

## Build (optional)

On macOS, run the helper to produce an app bundle under `dist/`:

- `./build.sh`

The script auto-includes the UCS CSV from `data/` and the macOS icon from `icons/mac/` if present.

## Runtime requirements

- Python 3.8+
- Tkinter available (for GUI)
